Design decisions

Decision Rationale Tradeoff Evidence
Wait for same-time dispatch completion before moving the simulated clock. Maintains chronological backtesting even with multiple event handlers. Handler concurrency does not make historical timestamps parallel. BacktestingDispatcher._dispatch_loop (L55) / BacktestingDispatcher._dispatch_events (L91)
Inject monetary and liquidity policies into the simulator. Fees, lending and fills use explicit exchange context. Live exchange semantics depend on the external adapter. Exchange.init (L98) / Exchange.create_order (L160) / Exchange._on_bar_event (L438) / OrderManager.on_bar_event (L87) / OrderManager.add_order (L93)
